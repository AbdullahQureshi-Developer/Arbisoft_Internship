# Week 4 Assignment: Research Agent

A research agent built with LangChain, featuring:
- Web Search capability (SerpAPI)
- File Reading capability (.txt and .pdf)
- Memory (recalls facts)
- Custom Tool Logging hook

## Setup

```bash
uv sync
```

## Run

**Console Demo:**
```bash
uv run agent-demo
```

**Streamlit UI:**
```bash
uv run agent-ui
```
